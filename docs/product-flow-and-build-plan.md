# Study Buddy Pet · 产品流程与搭建步骤

> 课程作业 MVP。角色设定使用 Princess Bubblegum，仅作课程概念演示；目前用占位角色（`art/placeholder/`）开发，最终精灵图替换即可，代码不用改。
>
> 完整产品方案（目标用户、安全合规、风险等）见 Claude Docs 里的「K-12 学习伙伴桌宠 · 产品方案」。本文件只管两件事：**产品怎么流转**、**按什么顺序搭出来**。

---

## 1. 系统组成

```
┌───────────── 孩子的电脑 ─────────────┐
│                                      │
│  app/  桌宠 (Electron)               │──┐
│   · 透明置顶窗口 + 精灵图动画          │  │
│   · 对话框 / 任务板 / 专注计时          │  │  HTTPS
│                                      │  │
│  extension/  Chrome 扩展             │──┤
│   · 解释一下 · 屏蔽网站 · 考试模式      │  │
└──────────────────────────────────────┘  │
                                          ▼
                              server/  后端 (Node.js)
                               · system prompt（按年级）
                               · 内容过滤 · 安全流程
                               · 任务 / 积分 / 考试模式状态
                                          │
                                          ▼
                                   Claude API
```

**原则：API key 只放在 `server/`，桌宠和扩展里都不放。**

MVP 阶段三个部分都跑在你自己的电脑上（server 用 `localhost`），不需要部署。

### 精灵图约定（所有角色版本通用）

| 行 | 状态 | 帧数 | 什么时候播放 |
| --- | --- | --- | --- |
| 0 | `idle` | 6 | 默认待机 |
| 1 | `thinking` | 6 | 等 Claude 回复 |
| 2 | `experiment` | 6 | 给线索、讲解概念 |
| 3 | `give-quest` | 6 | 拆解任务、展示任务板 |
| 4 | `celebrate` | 8 | 完成任务 |
| 5 | `encourage` | 4 | 答错 / 孩子说"好难" |
| 6 | `guard` | 6 | 考试模式进行中 |
| 7 | `sleep` | 4 | 休息时间 / 每日时长用完 |

换最终角色时：把新图放进 `art/final/`，保持同样的行顺序和格子尺寸，再改 app 里指向的路径即可。

## 3. 产品流程

### 3.1 孩子的一天（主流程）

1. 打开电脑 → 桌宠出现，播 `idle`，打招呼："今天有什么任务，英雄？"
2. 孩子点开**任务板** → 看到家长 / 老师布置的任务，或者自己加一个
3. 选一个任务 → 桌宠播 `give-quest`，把它拆成 3–6 个小步骤
4. 开始**专注计时**（如 25 分钟）→ 桌宠安静陪着
5. 中途卡住 → 点桌宠提问（见 3.2）
6. 完成一个步骤 → 打勾；全部完成 → 播 `celebrate`，加积分
7. 专注时间到 → 提醒休息、喝水
8. 当天使用时长到上限 → 播 `sleep`，"今天的冒险结束啦，明天见"

### 3.2 对话辅导

```
孩子输入问题
   │
   ▼
桌宠播 thinking ──► 后端：输入过滤
                      │
             ┌────────┴────────┐
         有安全风险          正常
             │                 │
     固定安全回复 +        加 system prompt
     引导找信任的大人      （年级 + 不给答案）
     （记录给家长）            │
                          调 Claude API
                               │
                          输出过滤
                               │
                     返回提问 / 线索（不给最终答案）
                               │
                 桌宠播 experiment，显示回复
                               │
              孩子答对 → celebrate   答错 → encourage + 下一个线索
```

线索分三级：**轻提示**（"你觉得第一步是什么？"）→ **中提示**（指出该用的概念）→ **重提示**（演示一道类似的题）。永远不直接给原题答案。

### 3.3 考试模式

1. 家长在家长页面点"开始考试模式"，设时长和屏蔽名单
2. 后端把状态改为 `exam: on` → 桌宠和扩展轮询拿到新状态
3. 桌宠切到 `guard`，对话框锁定，只显示"考试结束后我们再聊"
4. 扩展启用屏蔽规则（分心网站 + AI 工具网站）；屏幕角落显示"考试模式进行中"
5. 期间只记录：开始/结束时间、屏蔽次数、切出考试页面次数（**不录屏、不读网页内容、不记键盘**）
6. 时间到或家长手动结束 → 恢复正常，桌宠向孩子展示本次记录，家长看到同一份

### 3.4 家长流程（MVP 简化版）

- 一个本地网页 `localhost:3000/parent`
- 能做：添加任务、设每日时长上限、开始/结束考试模式、看今日总结（学习时长、完成任务数、常问科目）
- MVP 不做登录系统，用一个简单的家长 PIN 码

## 4. 搭建步骤

每个阶段结束都有一个能演示的东西。建议用 Claude Code 在这个文件夹里一步步做。

### 阶段 0 · 准备环境

- [ ] 安装 Node.js 20+（终端里 `node -v` 确认）
- [ ] 安装 VS Code（或你习惯的编辑器）
- [ ] 在 [Claude Console](https://console.anthropic.com) 申请 API key，充少量额度
- [ ] 在 `server/` 里建 `.env` 存 key，并把 `.env` 加进 `.gitignore`
- [ ] （可选）`git init`，每完成一步提交一次

### 阶段 1 · 会动的桌宠（不连 AI）

**目标：** 桌面上出现占位角色，会播动画，可以拖动。

- [ ] `app/` 里 `npm init -y` + `npm i -D electron`
- [ ] `main.js`：透明、无边框、置顶、不在任务栏的小窗口（约 200×220）
- [ ] `index.html` + `renderer.js`：读 `art/placeholder/pet.json`，用 canvas 按行/帧播放精灵图（约 8 fps）
- [ ] 透明区域点击穿透，角色本身可以拖动
- [ ] 加一个调试菜单（右键）：手动切换 8 个状态，确认每行动画都对
- **验收：** 右键切到每个状态，动画正确、不跳位

### 阶段 2 · 能对话（连 Claude）

**目标：** 点桌宠弹出对话框，桌宠用苏格拉底式提问回答。

- [ ] `server/`：`npm i express @anthropic-ai/sdk dotenv`
- [ ] `POST /chat`：接收 `{ grade, messages }`，拼 system prompt，调 Claude API，返回回复
- [ ] 写 system prompt（放 `server/prompts/tutor.md`）：年级语气、不给答案、三级线索、不扮演恋人或真人朋友、遇到安全话题按固定流程回复
- [ ] 简单的输入/输出过滤（MVP 可以先用关键词表 + 让模型自己标注风险）
- [ ] 桌宠：点击弹出对话气泡/小面板，发送时播 `thinking`，回复后播 `experiment`
- [ ] 每日对话次数上限（控制 API 费用）
- **验收：** 问一道数学作业题，桌宠不直接给答案，而是一步步引导

### 阶段 3 · 任务板 + 专注计时 + 积分

**目标：** 主流程（3.1）完整跑通。

- [ ] `server/` 用一个 JSON 文件（或 SQLite）存任务、积分、设置
- [ ] `POST /tasks/breakdown`：让 Claude 把一个大任务拆成 3–6 步（返回 JSON）
- [ ] 桌宠面板：任务列表、勾选、进度
- [ ] 番茄钟：开始/暂停，到点提醒休息
- [ ] 完成任务 → `celebrate` + 积分；每日时长上限 → `sleep`
- [ ] 家长页面 `localhost:3000/parent`（PIN 码）：加任务、设时长、看今日总结
- **验收：** 家长加一个任务 → 孩子在桌宠里拆解、计时、完成 → 家长页面看到记录

### 阶段 4 · Chrome 扩展 + 考试模式

**目标：** 考试模式（3.3）完整跑通。

- [ ] `extension/manifest.json`（Manifest V3），权限只要 `tabs`、`declarativeNetRequest`、`storage`
- [ ] 扩展每隔几秒向 `server` 查询考试模式状态
- [ ] 考试中：启用屏蔽规则，页面角落显示"考试模式进行中"
- [ ] 记录事件摘要并上报 `server`（只记次数和时间）
- [ ] 桌宠同步切到 `guard`、锁定对话
- [ ] 家长页面：开始/结束考试模式、设屏蔽名单
- [ ] （加分项）"解释一下"：右键菜单把选中文字发给桌宠讲解，需要单独申请权限
- **验收：** 家长开考试模式 → 打开被屏蔽网站被拦下 → 桌宠拒绝回答 → 结束后孩子和家长看到同一份记录

### 阶段 5 · 换上正式角色 + 打磨演示

- [ ] 用 ChatGPT 提示词（见对话记录）或自己画最终精灵图，放 `art/final/`
- [ ] 跑拼图脚本：去品红背景、对齐、拼成 1536×1664
- [ ] app 指向新图，逐个状态检查
- [ ] 角色台词风格调进 system prompt
- [ ] 准备演示脚本：主流程 → 对话辅导 → 考试模式，各 1–2 分钟
- [ ] 录一段演示视频备用

## 5. MVP 不做的事（写进作业里说明即可）

- 真实账户系统、年龄验证、家长可验证同意（COPPA）
- 部署到云端、多台设备同步
- 老师端和班级管理
- 语音对话
- 正式发布（角色版权、合规审查）

这些在产品方案文档的"安全与合规""路线图"里有说明，作业里注明"MVP 范围外"就好。

## 6. 下一步

从**阶段 0 → 阶段 1** 开始。阶段 1 完成后，你就有一个能在桌面上动起来的角色，可以先拿给同学或老师看反馈。
